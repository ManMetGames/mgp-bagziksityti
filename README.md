
# Timing-Based Combat System

This project is a third-person combat prototype developed in Unreal Engine.  
It focuses on implementing timing-based gameplay using animation-driven system.

The player must block incoming enemy attacks within a timing window to avoid damage.

https://mmutube.mmu.ac.uk/media/Mario_Bagyinszki_24827778_Unreal/1_ju0z1dph

## Controls
| Input | Action |
|------|--------|
| WASD | Move |
| Right Click | Parry |
## Features

- Third-person character controller
- Timing-based parry system (Quick time mechanic)
- Animation-driven attack system using AnimNotifies
- Enemy AI with movement and attack behaviour
- Character healthbar
